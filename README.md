# Lampa plugins

Расширения для Lampa.

## online_mod + Naruto Based

```
https://edembey.github.io/lampa-torbox/plugin/online_mod.js
```

Lampa → **Настройки** → **Расширения** → **Добавить расширение** → вставить ссылку.

После установки: фильм или сериал → **Онлайн** → **Naruto Based**.

## TorBox

```
https://edembey.github.io/lampa-torbox/plugin/torbox-lampa-plugin.js
```

После установки откройте настройки TorBox и вставьте **TorBox API-ключ**.
